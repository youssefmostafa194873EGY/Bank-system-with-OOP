A banking system developed using Object-Oriented Programming (OOP) and organized into classes, featuring:

1- A login screen.

2- A list of customers.

3- Addition of new customers.

4- Modification of existing customer data.

5- Search functionality for customers.

6- Transaction management, including: debiting/crediting customer balances, viewing total balances, transferring funds between customers, and a log of balance changes linked to specific user accounts.

7- User management, including: a list of users, adding/deleting/modifying user accounts, searching for users, and assigning specific access permissions for different parts of the application.

8- A log of application login history.

9- A currency exchange system, featuring: a list of global currencies (relative to the US Dollar), currency search, exchange rate adjustments, and a calculator for converting amounts between different currencies.
